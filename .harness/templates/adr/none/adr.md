# 결정 기록

**이 프로젝트는 별도의 결정 기록을 두지 않는다.**

**이 파일은 harness.toml 에서 생성된다. 직접 고치지 않는다** — 결정 기록을 쓰기로 하면
`[adr]` 의 `style` 을 `nygard` 또는 `madr` 로 바꾸고 `harness render` 를 돌린다.

## 역할이 알아야 할 것

- **결정 기록 대상 여부를 판정하지 않는다.** 판정이 필요한 자리에서는 항상 "불필요" 다.
- **결정 게이트에서 기록 여부를 묻지 않는다.** 물을 것이 없다.
- **검토한 대안과 기각 근거는 이슈와 리뷰 요청 본문에 남긴다.** 결정 기록이 없어도 대안이
  사라지는 것이 아니라 위치가 다를 뿐이다 — 리뷰 요청 본문이 그 유일한 기록이므로 빠뜨리지 않는다.
- 근거 우선순위에서 결정 기록 자리는 비어 있다. `.ai/project/` 의 기준 문서가 최상위다.

## 무엇을 잃는가

되돌리기 비싼 결정의 "왜" 가 리뷰 요청 본문에만 남는다. 그 리뷰 요청을 찾지 못하면 근거를
따라갈 수 없다. 같은 주제로 "왜 이렇게 했지" 가 반복되면 그때 스타일을 켠다.
