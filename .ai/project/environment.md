### 필요한 도구

| 도구 | 용도 | 확인 |
|---|---|---|
| JDK 21 | 빌드·실행 | `java -version` |
| Maven Wrapper | 빌드. 리포에 포함돼 별도 설치가 필요 없다 | `./mvnw -v` |
| `gh` | 이슈·리뷰 요청 조회와 생성 | `gh auth status` |
| `harness` | 생성 파일 관리 | `harness version` |
| `adr` (adr-tools) | 결정 기록 생성 | `adr help` |

### 환경 변수

| 이름 | 용도 | 어디서 얻나 |
|---|---|---|
| `HARNESS_USAGE_LOG` | 사용 기록 위치를 덮어쓴다. 비우면 `$HOME/.harness/silent-room/usage.log` | 설정하지 않아도 된다 |

서비스 자체가 요구하는 환경 변수는 없다. 외부 자격증명을 쓰지 않는다.

### 외부 시스템

없음. 외부 API·데이터베이스·메시지 브로커에 붙지 않는다.
