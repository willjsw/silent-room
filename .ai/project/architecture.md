### 계층과 의존 방향

헥사고날. `domain` ← `application` ← `adapter`, 조립은 `SilentRoomApplication`.

현재 `src/main/java/com/willjsw/silentroom/` 에는 진입점 하나뿐이고 계층 패키지는 비어 있다.
**새 클래스는 아래 세 곳 중 하나에 넣는다.**

| 패키지 | 역할 | import 할 수 있는 것 |
|---|---|---|
| `domain` | 방·참가자·신호의 규칙. 순수 함수와 값 객체 | `java.*` 만 |
| `application` | 유스케이스 조립. 포트 인터페이스 선언 | `java.*`, `domain` |
| `adapter` | WebSocket·HTTP·저장소 구현 | 전부 |

### 검사하는 것

`script/verify-project.sh` 가 `domain` 패키지 파일의 `import` 를 grep 한다.
`java.` 로 시작하지 않는 import 가 하나라도 있으면 종료 코드 1 이다.
Spring, Jackson, Lombok 이 모두 걸린다.

검사와 이 문서가 어긋나면 둘 다 고친다.

### 검사하지 않는 것 (현재 상태 기록)

`application` 이 `adapter` 를 import 하지 않는지는 기계로 보지 않는다. 계층 패키지가
아직 비어 있어 검사할 대상이 없다. 첫 유스케이스가 들어올 때 검사를 함께 올린다.

### 아키텍처 특성

- **"말할 수 없다" 는 제약을 서버가 지킨다.** 자유 텍스트를 받는 필드·엔드포인트를
  만들지 않는다. 클라이언트가 막는 것으로 대신하지 않는다.
- **신호 종류는 열거형으로 닫는다.** 문자열로 열어 두면 그 자리가 곧 메시지 필드가 된다.
- **방 상태는 인스턴스 로컬 메모리에 있다.** 인스턴스 간 공유가 필요해지는 설계는 ADR 대상이다.
- 채널별 차이가 생기면 새 계층이 아니라 `adapter` 아래 구현을 더해 흡수한다.
