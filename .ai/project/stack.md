Java 21 / Spring Boot / Maven Wrapper. base package `com.willjsw.silentroom`.
포맷은 Spotless(google-java-format).

**정확한 버전과 의존성 목록은 `pom.xml` 이 정본이다.**

아직 미도입: 영속 저장소, Redis, Testcontainers, Actuator.
방 상태는 현재 인스턴스 로컬 메모리에만 있다.
